# 🧠 DSA Zero to Hero

A curated collection of Data Structures & Algorithms (DSA) problems and solutions, implemented in Java. These have been covered in **Apna College**'s ALPHA Batch 1 🔥  

---

## 📂 Repository Structure

* All code is written in **Java** (.java files).
* Each problem resides in its own file, often grouped by theme (e.g. DP, Graphs, Trees, etc.).
* Examples of included topics:

  * **Dynamic Programming**: Knapsack, Coin Change, Climbing Stairs
  * **Graph Algorithms**: BFS, Bellman–Ford, Prims, Tarjan’s Articulation Points
  * **Tree & BST**: Traversals, Building Trees
  * **Sorting & Searching**: Bubble Sort, Next Greater Element
  * **Greedy & Bit Manipulation**, Recursion, Linked Lists, etc.

## 🚀 Getting Started

### Prerequisites

* Java JDK 8 or later
* An IDE (IntelliJ, Eclipse, VSCode, etc.)
* Optional: Git for version control

### Clone the Repo

```bash
git clone https://github.com/rishu8090/DSA-Zero-to-Hero.git
cd DSA-Zero-to-Hero
```

### Compile & Run

1. Locate the `.java` file for the problem you wish to run.
2. Compile:

   ```bash
   javac ProblemName.java
   ```
3. Run:

   ```bash
   java ProblemName
   ```
4. Modify input/output sections as needed for custom testing.
